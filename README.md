# 🛔 School Bell / Школьные звонки

Автоматизация школьных звонков с гибким расписанием, музыкой на переменах и темами оформления.

## ✨ Возможности

- **Автоматические звонки** — начало и конец уроков по расписанию
- **Музыка на переменах** — случайный трек через 2 мин после звонка, без повторов в день
- **Светлая/тёмная тема** — переключение в настройках
- **Умный редактор** — длительность урока с авто-расчётом окончания, перемены 5–30 мин
- **Гибкое расписание** — обычное, сокращённое или пустое для каждого дня
- **Два языка** — русский и английский

## ⚙️ Настройка

### Расписание (`schedule.yml`)

```yaml
days:
  monday: usual
  tuesday: usual
  wednesday: usual
  thursday: usual
  friday: usual
  saturday: none
  sunday: none

schedules:
  usual:
    - { num: 1, start: "08:30", end: "09:10" }
    - { num: 2, start: "09:20", end: "10:00" }

sounds:
  start: sounds/Ringin.wav
  end: sounds/Ringinout.wav
```

### Музыка на переменах

1. Создайте папку `music/`
2. Положите аудиофайлы (`.mp3`, `.wav`, `.ogg`, `.flac`, `.m4a`)
3. **Настройки → Музыка на переменах** → выберите папку

Музыка играет через 2 минуты после звонка на перемену. Треки не повторяются в течение дня.

> 💡 **Совет:** Создавайте тематические плейлисты в разных папках (например, `music/patriotic/`, `music/space/`) и меняйте папку в настройках каждую неделю.

## 🎨 Темы

**Настройки → Тема** → Светлая / Тёмная

Тема сохраняется и применяется при следующем запуске.

## 🌐 Язык

**Настройки → Language / Язык** → Русский / English

## 📝 Редактирование расписания

1. Выберите день (Пн, Вт, ...)
2. **Редактировать расписание**
3. Добавьте урок:
   - Время начала
   - Длительность урока (окончание рассчитается автоматически)
   - Перемена после урока (5, 10, 15, 20, 25 или 30 мин)

## 🔧 Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| `Ctrl+O` | Загрузить расписание |
| `Ctrl+S` | Сохранить расписание |
| `Ctrl+T` | Сегодня |
| `Ctrl+Q` | Выход |
