# 🛔 School Bell / Школьные звонки

Приложение для автоматизации школьных звонков с поддержкой расписания, темной темы и музыки на переменах.

## ✨ Возможности

- **Автоматические звонки** — начало и конец уроков по расписанию
- **Гибкое расписание** — обычное, сокращённое или пустое для каждого дня недели
- **Светлая/тёмная тема** — переключение в меню настроек
- **Музыка на переменах** — случайный трек из указанной папки через 2 минуты после звонка (без повторов в течение дня)
- **Редактирование расписания** — указание длительности урока с авто-расчётом окончания, выбор длительности перемены (5–30 минут)
- **Два языка** — русский и английский
- **Сохранение настроек** — расписание, звуки, тема, язык

## ⚙️ Настройка

### Расписание

Файл `schedule.yml` содержит шаблоны расписаний и настройки дней недели:

```yaml
days:
  monday: usual
  tuesday: usual
  wednesday: usual
  thursday: usual
  friday: usual
  saturday: none
  sunday: none

schedules:
  usual:
    - { num: 1, start: "08:30", end: "09:10" }
    - { num: 2, start: "09:20", end: "10:00" }

  short:
    - { num: 1, start: "08:30", end: "09:00" }

sounds:
  start: sounds/Ringin.wav
  end: sounds/Ringinout.wav

break_duration: 10

music:
  enabled: true
  folder: /path/to/music
```

### Музыка на переменах

1. Создайте папку `music/` в корне проекта
2. Положите туда аудиофайлы (`.wav`, `.mp3`, `.ogg`, `.flac`, `.m4a`)
3. В меню **Настройки → Настроить звуки** выберите папку с музыкой
4. Музыка включится автоматически и будет играть через 2 минуты после звонка на перемену

Треки не повторяются в течение дня. Когда все треки сыграны, список сбрасывается.

## 🎨 Темы

Переключение тем: **Настройки → Тема → Светлая / Тёмная**

Тема сохраняется в `preferences.yml` и применяется при следующем запуске.

## 🌐 Язык

Переключение языка: **Настройки → Language / Язык → Русский / English**

Язык сохраняется в `preferences.yml`.

## 📝 Редактирование расписания

1. Выберите день недели (кнопки Пн, Вт, ...)
2. Нажмите **✏️ Редактировать расписание**
3. Добавьте урок, указав:
   - Номер урока
   - Время начала
   - Длительность (окончание рассчитается автоматически)
   - Длительность перемены после урока (5, 10, 15, 20, 25 или 30 минут)
4. Сохраните изменения

## 🔧 Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| `Ctrl+O` | Загрузить расписание |
| `Ctrl+S` | Сохранить расписание |
| `Ctrl+T` | Показать расписание на сегодня |
| `Ctrl+E` | Редактировать текущий день |
| `Ctrl+Q` | Выход |
| `F1` | Тест звонка начала урока |
| `F2` | Тест звонка конца урока |
